GitHub連携の設定

トークンを設定すると、演習終了時にアプリが自動で記録を保存し、AI苦手分析まで自動実行されます。

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → kashikinn
  3. Permissions → Repository permissions → Contents: Read and write
  4. 生成されたトークン（github_pat_…）を下に貼り付けて保存

トークンはこの端末のブラウザ内にのみ保存されます（リポジトリには送信されません）。

試験日の設定
